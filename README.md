# Strategic Recruitment & Talent Acquisition Analytics

## Project Overview

This project analyzes recruitment data of 1,493 candidates using SQL and Power BI to identify factors influencing hiring decisions and evaluate recruitment strategy effectiveness.

## Tools Used

- SQL
- Power BI
- Excel

## Key Findings

- Hiring Rate: 30.9%
- Skill Score was the strongest factor associated with hiring.
- Aggressive Recruitment Strategy achieved the highest hiring rate (71.6%).
- Master's and PhD candidates had higher hiring success rates.

## Dashboard Features

- KPI Cards
- Hiring Funnel Analysis
- Recruitment Strategy Analysis
- Education-Level Insights
- Candidate Assessment Analysis
- Interactive Slicers
